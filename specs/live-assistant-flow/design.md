# 实现设计

AssistantCore 增加可迁移的场次、消息、操作记录、练习题模型。Store 维持 UI 兼容，新的运行时模块负责场次与定时任务。工具注册表统一描述与参数校验，ProviderAPI 接 tool calling，平台适配封装 SDK/API。

生成期间捕获场次与能力版本；发送前再次校验；未知发送结果不自动重试。知识库采用本场独立沉淀文档更新，避免累积重复与污染现有资料。课堂转写与持久场次不依赖课程产物开关。

验证：Swift 单元/集成测试覆盖持久化迁移、双处理人记录、聚合、过期任务、关闭开关、发送失败、练习题校验、工具分派。构建开发包；实际外部服务联调另行报告。

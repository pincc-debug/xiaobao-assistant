# 课堂问答检索

当前实现（0.2.6）：

- 数据范围：所选知识库、本场转写、本场主讲回答。助教回答不自动加入本场回答依据。
- 分段：优先完整句段；FAQ 按问答对分段。超长问答保留问题上下文。
- 本地缓存：`retrieval-v1.json`，以模型版本、维度及内容的 SHA-256 为键，只存向量，不存密钥或原文；文件权限 0600。
- 配置：复用语音转写的北京地域百炼密钥，固定 `text-embedding-v4`（1024维）和 `gte-rerank-v2`，无新增配置项。
- 更新：启动、资料保存、课堂转写及主讲回答持久化后后台准备索引，2秒合并更新；失败60秒后允许后续事件重试。仅变化片段重新计算。旧缓存不会成为召回源，召回范围始终以本次课程快照为准。
- 召回：字符词组加权检索与已就绪的语义向量各取20段，RRF合并至24段，再重排序取6段。候选不足时补充当前资料，帮助小知识库冷启动。最近2段课堂转写额外保留。
- 课堂提问不会等待全部资料建立索引。尚未建立索引的大资料库可能漏召回，任务时间线会明确提示。云服务失败时回退到现有检索结果，不冒充完整语义检索成功。
- 回答：模型判定资料足够并返回引用；程序校验引用及数字；通过后直接回复，不再调用决策模型二次复核；模型判定不能回答或程序校验失败时转交主讲。
- 来源：课堂转写及主讲回答附本场ID、来源类型和记录时间。旧资料没有日期的保持未知，不虚构时效。

## 验证边界

离线测试覆盖同义问法的向量召回、超出关键词候选范围的答案、重启缓存、增量更新、无效向量、删除资料隔离、最新转写、降级及冲突转交。

测试中的模型输出使用可控替身，验证流程，不代表真实模型准确率。需后续用视频测试集验证云服务连通性、同义词/转写错误、误答率、转交率和端到端耗时；当前不自动判断原始资料是否已过期，也不对转写错字强行纠正。

# 主讲备答（0.2.11）

自动答疑无法确认答案时，先把问题转给主讲，再复用本轮检索片段准备备答材料，不重新检索。

- 部分依据：给出有依据部分的建议答案、原文来源和待确认事项。
- 资料冲突：展示不同原文及待确认事项，不生成可发送答案。
- 无依据或校验不通过：只提示资料不足，不提供猜测答案。

生成后检查原文引用、数字及独立依据核验。建议不写入输入框，也不自动发送。回答窗口中“采纳并发送”位于建议内容下方；讲师点击才引用原消息发送。输入框始终留给讲师自行填写；已有草稿时禁用采纳，避免误操作。发送成功后进入课堂问答并移除待答，失败保留建议和空输入框供检查重试。

测试覆盖部分建议、冲突、伪造依据、无资料、场次切换、采纳不填输入框、重复点击防重及发送失败。未启动软件、未覆盖安装；真实模型及视觉效果待实播验收。

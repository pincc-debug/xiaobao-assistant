# 主讲口述跟进答疑

在现有“智能答疑”能力开启时工作，不新增开关。已完成的课堂转写仍实时加入本场回答资料；新增流程主动扫描最近两分钟最多24段转写，与最多30个未处理、未编辑且有原消息的待答问题匹配。转写安静2秒后开始核验。

第一步回答模型最多返回3个明确匹配的问题、简短答案和连续原话，必须引用已提供的转写ID。程序要求依据出现在提问之后，检查原话真实存在及答案数字来源；第二步决策模型结合全部上下文核验完整性、否定、纠正和歧义。未通过保留问题，不执行任何转写中的操作指令。

核验期间有新增转写、能力关闭、场次变化、讲师进入问题编辑或已输入草稿时不自动发送。通过后引用第一条原提问，发送确认后移出待答，并在课程问答保存“主讲口述，助教整理”、原话、转写ID和时间。发送未确认时保留草稿和原话来源，不自动重发，避免重复消息。

验证使用模型与发送通道替身，覆盖引用与沉淀、未通过核验、伪造依据、提问之前的旧内容、发送失败、讲师编辑及核验中新增纠正。模型是否能正确理解真实口述仍需实播验证；麦克风不能可靠区分说话人，不启用声纹判断。

# 消息类型标识

圆形文字徽标统一用于大小卡片：问/题/签/告/析/助/聊；反馈按内容显示卡/屏/声，其他反馈显示报。徽标带可访问名称，不仅依靠颜色区分。人数和操作按钮同时显示；反馈不计入主讲待答问题数量。分析结果保留原有消息流通知和笔记沉淀。

仅做代码与编译验证；没有启动软件，实际多屏、字号和鼠标交互未验收。

# 大卡片布局（0.2.9）

左侧仅“课堂 / 笔记 / 记录”。课堂页独立承载进行中互动、待答问题、反馈和短暂消息流；笔记和记录页不再重复显示互动卡片及公屏消息。

- 顶部：进行中卡片，限定高度独立滚动，保留状态、统计、简短分析、结束按钮。
- 中间：待答问题与可用依据；课堂反馈在问题下方独立弱化分组。
- 底部：短暂公屏消息和助教动态，不参与待答列表布局。
- 答题详情在原互动卡片内展开，展示选项内容与人数；签到详情展开实际签到名单。
- 空分组隐藏，不同时显示多个“暂无”。顶部去掉已回答/金句累计数字，仅有待答时显示数量。

编译打包通过。遵照用户要求未启动软件、未覆盖安装；实际视觉、滚动及多屏效果尚未验收。

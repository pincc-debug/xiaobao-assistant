# 教室、备课和课程会话

## 身份与生命周期

- 教室以规范化频道号作为唯一标识，可以提前创建。名称可选。0.3.2 起，新建教室、新建课程和开课前均在线核对频道归属，详见 [频道归属校验](channel-ownership.md)。
- 每节课有独立会话ID。课程状态只有备课中、上课中、复盘中。确认备课仍属于备课中；开播并获得平台sessionId后转入本场。平台场次确认后，备课对话和资料关联到本场课程ID，并保留备课到课程的映射。未确认的旧记录不会被覆盖。
- 无备课开播时自动生成新课程，教室由频道聚合显示。
- `(channel, platformSessionId)`识别同场，重连继续原记录。未结束的已有平台场次优先，断线重连时误选的下一课备课不会被消耗。主讲已下课的场次保持复盘中，即使平台返回相同sessionId，再次上课也创建新课程。平台场次缺失时只能标为未核实，不承诺判断两次连接是否为同一场。
- 每课聊天和生成资料按lessonID隔离，教室知识库共享。旧版没有lessonID的聊天保留为“历史讨论”。跨课复盘由查询工具显式读同教室课程，不自动拼入其他课聊天。

## 开课选择

选择备课课程时自动带出频道；手填频道则过滤待开课课程。课程下拉始终提供“新建一节课”。公共知识库独立选择，其ID随课程保存，重连恢复选择。已使用备课不会再次列入待开课课程，可在教室复制为新课。

备课先保存草稿，确认后可用于上课。模型更新草稿会撤销确认状态；旧编辑窗口的过期保存被拒绝。只有平台场次已确认时，才原子写入备课快照并标记已使用。当前课答疑使用确认快照及本场公共知识库，不读取其他课未确认草稿。

## 资料与验证

导入支持文字PDF、UTF-8 TXT/Markdown和RTF；单文件不超过20MB、10万字。备课可参考已有知识库，开课关联时冻结参考资料版本。确认内容可以手动存入知识库；重复保存相同版本不会创建副本。

自动化覆盖：频道规范化、无备课开课、重复开播、同场重连、备课消耗时点、快照不可变、错误频道、未确认草稿、课程聊天隔离、知识库去重、过期编辑拒绝和旧格式迁移。日志位于evidence/preparation。真实平台场次行为及模型效果仍需真实频道联调。


## 每课资产包

资产按备课、课堂记录、复盘三组保存，类型区分文档和结构化答题卡。生成后自动属于当前课程，不再要求“加入本课”。阶段由发起任务时的课程状态确定并落盘，后续开播/下课不改变已有资产归属。每条完成消息保留此次产出的资产ID，支持重新打开相应分组。

确认备课后冻结本场文档与题目快照。题目与知识文档分开保存，题目答案不自动混入公共答疑知识。课后新产出归入复盘；“用于下次备课”复制为新课，原课保持不变。已开课的备课版本不可直接编辑，课程聊天仍可一直继续。

### 答题卡

目前支持2–5选项的单选/多选题，包含正确答案、解析、原文依据。AI生成时只保存本课草稿。确认备课后尝试保存到频道题库，或由用户单独保存；不会发起答题。

保存使用官方 `POST /live/v3/channel/interact/question/add-edit-question`，已有题目携带questionId更新。发送沿用官方互动SDK `AnswerCard.start`，仅在本场通过按钮或语音明确发起。已确认备课题目在关联课程时进入本场题目列表。

创建前保存同题已有ID作为检查点；响应不确定时只查询、对账，不盲目再次创建。保存与发送互斥，保存状态不明确时禁止发起。缺少权限或配置时保留本地题目，不显示成功。

接口依据：https://help.polyv.net/live/api/live_interaction/add_edit_question/ 。本地官方SDK也将saveQuestion与start分开；前者调用add-question，后者调用createTestQuestion。没有执行真实平台创建或发送，写入路径仅使用模拟传输验证。

### 本机模型

以下为 0.3.1 历史验证记录；0.3.3 已移除本机 Codex，当前使用 API 服务原生工具调用，见 [聊天流式输出](chat-streaming.md)。

旧版 Codex文本适配器显式说明“返回宿主业务工具JSON”不等于调用Codex内置工具，避免误判工具不可用。工具决策优先使用所选模型明确支持的low推理配置，否则用其声明的默认配置；仅覆盖单次turn，不修改用户全局配置、不更换模型。参考：https://learn.chatgpt.com/docs/app-server 。

真实模型使用用户已配置的模型与合成课程数据验证，不读取真实课程、不发送课堂消息。草稿修改与“文档+结构化题目”产出各有单独日志。首次超时/工具不可用失败日志保留，成功记录见real-model-protocol.log及real-assets.log。后续low推理配置的速度复测遇到本机Codex账号路由发现失败（workspace routing discovery failed），未验证速度改善；该错误已映射为可重试的服务不可用提示，不改变用户账号配置。

## 本轮验收限制

用户要求不打开应用，已停止界面操作；旧的开课窗口测试改为XB_UI_TESTS=1才运行。新增界面仅编译通过，未完成实际视觉/交互验收。新安装包生成后不自动启动、不覆盖正在运行的正式应用。真实平台频道场次联调仍缺可用频道号。

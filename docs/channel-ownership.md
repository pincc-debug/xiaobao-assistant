# 频道归属校验（0.3.2 / build 28）

新建教室、教室内新建课程、开始上课均先在线校验频道。入口为 `createClassroom`、`createValidatedPreparation`、`connect`。原有同步 `createPreparation` 是内部本地数据操作，供复制、测试等使用；无权放行开课。复制资料不调用平台，实际开课仍重新校验。

使用当前配置的 App ID / App Secret 签名只读 GET `/live/v4/channel/basic/get`，核对返回频道号及 `userCategory.userId`、`authSettings[].userId` 与配置的 User ID。分类为空时允许使用观看条件里的账号字段；全部缺失、不同字段冲突、频道不匹配、请求失败都拒绝继续。不能仅以 Token 获取成功推断归属，也不从观看地址猜账号。

依据：[保利威查询频道信息文档](https://help.polyv.net/live/api/v4/channel/operate/get_channel_detail/)。沿用应用已有的用户自填凭据机制，不新增运行时或依赖。接口响应可能包含频道密码，仅解析归属字段，不落盘、不写日志、不直接展示服务端原始错误。

请求超时 15 秒，不缓存校验结果。校验期间禁止重复提交，可取消；取消后即使返回成功也不保存或连接。账号更改后旧结果无效；开课期间更换频道或所选备课须重新提交。校验失败发生在清理旧课堂、连接聊天室、创建直播记录及消耗备课之前。

验证：新增 10 个非界面测试，覆盖请求签名、归属相符/不符/缺失/冲突、错误频道、HTTP/业务/解析失败、缺少凭据、超时、取消、账号变更、重复连接及失败不消耗备课、不写资料。全量无界面测试 143 通过、5 项显式跳过。无真实账号联调、无界面验收；不打开或覆盖安装应用。记录在 `evidence/channel-ownership/`。

本次为本地功能修复，没有新增远程业务知识条目。

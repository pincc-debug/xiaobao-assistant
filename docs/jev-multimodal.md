# Jev 图片能力核实

核实日期：2026-10-15。

官方在2026-10-14的发布说明公开图片输入，1.13和1.14均支持，需请求头 TypeSafe-Danger-Zone-Images: true；输入资源通过 assets 引用。1.14新增box问题返回边界框。官方将这些能力标记为实验性；不是可靠性保证。

模型文档明确不直接接收音频和视频。音频仍需ASR转写；视频可另行抽帧用于图片判断，但这不是直接视频输入。

本项目当前实现仍只向Jev发送文本/JSON，没有接入图片assets或实验请求头。本轮没有自动启用多模态，也没有为未实现能力添加复选框。

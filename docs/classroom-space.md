# 教室工作区

2026-10-16。阶段：已有功能改流程，沿用原生视觉。主动作是选教室后对话复盘，再查看并保存有来源的资料。右侧按备课、课程、资料、题目和数据展开；不增加解释性副标题。未开启独立视觉评审。

## 当前实现

- 教室按频道组织，支持提前创建。课程内独立聊天、备课、资料；右侧应用栏保留历史详情与删除/撤销。详见 `preparation-sessions.md`。
- Swift工具循环：列课程、分段读课、检索课程/关联知识库、生成资料或题目草稿。用户选择知识库保存，原始来源一并保留，保存后自动关联该知识库。
- 上下文按64,000字节序列化输入预算组织，给工具结果预留最多24,000字节；最近消息完整保留，相关旧消息自动补入。完整聊天在本机保存，可通过search_conversation/list_conversation/read_conversation找回。没有模型摘要，不承诺无限记忆或精确token预算。系统提示、工具schema和输出还需额外上下文空间，实际模型兼容性需联调。
- 同一教室禁止同时发送多个任务，切换教室不混入聊天，停止后不接收迟到结果。保存先写盘后提交界面状态，失败保留草稿；重复保存去重。
- Pi只在agent-runtime目录做过依赖核查，未接入、未打包，用户已决定暂停。直播语音仍使用现有原生工具流程。

## 直播后数据接入调查

已读现有Swift源码及保利威官方接口文档；未调用真实客户统计接口、未查询客户数据库。以下接口已接入原生实现；已用确定性响应测试调用、解析、分页和异常路径，尚无实际频道场次用于真实API联调。

| 数据 | 现状及接口 |
|---|---|
| 学生发言 | 实时额外保存各角色公聊记录，学生实时分类流程保持原样；图片/文件保留类型占位。平台补拉仅纳入频道及sessionId一致的已审核公聊，不包含私聊或已删除记录。原始互动与问答、转写均可用于教室检索。 |
| 完整聊天补拉 | `/live/v3/channel/chat/get-history-page`，按频道、时间、角色分页。返回sessionId及quote，可按场次归属并保留引用关系；审核/删除、私聊与子房间须分别定义范围，不能直接宣称所有互动都齐全。 |
| 讲课内容 | ASR转写及带时间的片段、知识点和问答已有本地记录。转写受录音开启时间、断线和识别质量限制，不等于原始备课稿。 |
| 场次运营概况 | `/live/v4/statistics/session-stats/summary/list`，包含观看人数、观看次数、最高并发、平均/总观看时长等。按指定历史频道查询，精确核对sessionId后保存运营指标；不依赖当前连接频道。 |
| 历史趋势 | `/live/v3/channel/statistics/concurrence`，按日期查询，返回day/minute/viewers；需按实际场次起止时间截取。接口说明最多查两个月跨度，不据此推断数据保留期。 |
| 实时趋势 | `/live/v2/statistics/get-realtime-viewers`，返回近期count/time点；点数和间隔可能调整，不写死，也不能据此补齐完整历史。 |

统一频道+平台sessionId+时间边界。并发、观看人数、观看次数分开；缺失不作零；在线下降不直接推断离场人数或讲课导致流失。统计生成时延、账户授权、时间口径及实际响应还需真实接口联调。

官方服务端API使用签名鉴权。正式分发时应按官方要求通过授权服务端中转，不能把共享appSecret嵌入应用。历史查询已与gateway的当前连接频道解耦，避免查询错频道。

原生预览已操作：频道切换、复盘草稿生成、展开资料、保存新知识库、题目答案展开、历史课程详情。预览模型返回为隔离的确定性测试数据，不证明真实LLM效果。静态查看发现侧面板分割线方向错误并已修正；完整动效录屏未验收。

自动化覆盖频道隔离、旧格式迁移、工具循环、保存读回/失败/重复、取消迟到结果、150条短消息、长输入预算和早期聊天检索；日志在evidence/classroom。未做生产模型、真实ASR或运营数据端到端联调。


## 数据面板验收与调度

- 工作台新增“数据”，教室右侧新增“数据”，课程详情增加同名页。当前在线、发言人数、已答和待答为首屏；在线曲线、每分钟发言、平台概况、已识别高频问题、互动与可搜索公聊向下展开。
- 实时每15秒请求一次；失败按30/60/120秒退避。超过90秒的在线样本显示为过期，保留曲线。实时采样按上海时区解析跨午夜时间，拒绝其他频道、未来或过旧点。曲线超过90秒缺口断开。
- 统计查询捕获频道及凭据，提交时核对账号和场次；历史刷新同场串行、最多2场并行、单场最短30秒、线上请求统一至少间隔1秒。直播中每5分钟触发一次历史同步；下课立即尝试，并在45秒后再次尝试。该等待不保证平台汇总已最终生成；可手动再次更新。
- 公聊每页1000条，每批最多20页，每页成功落盘后推进游标；中断保留固定时间窗和下一页。未能确认sessionId的记录不纳入。实际时间范围与同步终点作为复盘依据，不宣称全量。
- 平台观看UV、PV、并发、观看分钟分开；问答数量来自应用处理记录，不推演成全平台问答总量。在线下降不得直接归因或换算成流失人数。
- 本机验证：三轮相关测试记录在tests-data-final-*.log；真实界面使用隔离预览数据。live-data.png为课中图表截图。长时运行、真实大频道规模及平台权限/延迟仍待实测。
- 无独立视觉评审；窗口实看，未完成动效录屏。UI仅保留标题、数值、来源范围、更新时间和必要错误；没有框架或进程说明。

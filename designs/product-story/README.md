# 小保助教 · 产品宣讲

双击 index.html 即可离线播放。9 页，16:9，第 9 页再前进一步展示 Logo 与释义。

- ← / → / 空格：翻页
- 数字 1–9：直达页面
- F：全屏
- H：隐藏 / 恢复控制栏（录制时使用）
- N：显示 / 隐藏逐页口播备注；展开后口播稿显示在顶部，PPT 完整显示在下方
- O：页面总览
- Esc：关闭浮层并恢复控制栏
- 触屏：左右滑动；建议横屏

带稿录制：先打开备注，再用区域录屏框选下方完整的 16:9 主画面。翻页时画面区域保持固定，上方备注不在录制范围内。

录制：打开 → F 全屏 → H 隐藏控制栏 → 用方向键推进。最后的 Logo 是第 9 页内的第二幕。前进到 Logo 后，向左返回收尾。

文字和图解为 HTML 元素；仅封面淡背景由 AI 生成，Logo 复用项目原始素材。此演示表达产品理念与概念，不代表所有能力均已完成生产验收。

维护：修改 deck.template.html 后运行 `python3 build.py`。index.html 已内嵌图片和依赖，可单独拷贝。Alpine 源文件随 vendor/ 保存；播放与重新生成均无网络依赖。

方向比较：directions.html。设计说明：design-notes.md。截图、动效与评审：evidence/。
